# Backlog de produto
Artefato organizado a partir da Atividade 4 de Concepção do Sistema.

As Issues do GitHub devem ser criadas a partir dos itens deste backlog. Cada item corresponde a uma funcionalidade implementável e pode ser acompanhado no GitHub Project/Kanban.

**Escala de prioridade adotada no GitHub Project:** P0 = alta, P1 = média e P2 = baixa.
