# BNCC Play Mobile 1.0.0

Entrega final do aplicativo mobile desenvolvido em Flutter para a disciplina de
Engenharia de Software.

## Principais funcionalidades

- autenticação, cadastro e edição de perfis de professor e aluno;
- questões organizadas pelos eixos da BNCC Computação, categoria e dificuldade;
- quiz gamificado com pontuação e histórico de respostas;
- ranking geral e por eixo;
- dashboard pedagógico e relatórios de desempenho;
- sala multiplayer simulada localmente;
- banco SQLite local, sem dependência de servidor.

## Instalação

Baixe o arquivo `bncc-play.apk` em um aparelho com Android 7.0 ou superior e
abra-o para instalar. Se necessário, permita temporariamente a instalação de
aplicativos de fontes desconhecidas para o navegador ou gerenciador de arquivos.
